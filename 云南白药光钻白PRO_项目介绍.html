1项目概述

项目背景

云南白药光钻白PRO牙膏详情页是第18届全国大学生广告艺术大赛（大广赛）的参赛作品。页面围绕云南白药光钻白PRO牙膏「护口有方，钻白闪耀」的核心主张，面向年轻消费群体，打造一款兼具品牌调性与电商转化力的沉浸式产品详情页。

设计目标

品牌传达

以云南白药124年的制药底蕴为信任背书，传递「医药科技，提升口腔健康」的品牌理念

教育转化

破除「美白＝伤牙」的社会误区，建立「先护口，再钻白」的产品认知

社会价值

以真实数据揭示中国国民口腔健康危机，将产品价值嵌入社会问题语境

互动体验

通过拖拽对比、知识闯关等交互设计提升用户参与感和停留时长

目标受众

  • 18–35岁有一线城市消费习惯的年轻群体
  • 关注牙齿美白但担心"伤牙"的潜在消费者
  • 有牙渍、牙龈出血、牙齿敏感等常见口腔问题的用户
  • 偏好国货、支持民族品牌的新一代消费者

2社会问题回应

中国国民口腔健康现状

页面核心创新之一是将社会问题数据融入产品叙事。在品牌传承之后、产品介绍之前，专门设置了「国民口腔健康现状」数据板块，建立"为什么需要这款产品"的紧迫感。

指标数据来源
35-44岁成年人牙结石检出率96.7%第四次全国口腔健康流行病学调查
成年人牙龈出血检出率87.4%同上（较十年前上升10.1pp）
35岁以上牙齿敏感患病率>58%中华口腔医学会
中国牙周病患者总数9亿《促进牙周健康中国专家建议》
受访者受牙渍困扰比例51.04%2025居民口腔健康消费白皮书

社会问题与产品的关联逻辑

数据板块的叙事线索遵循三层结构：

1 问题揭示 ——"每10个中国人，9个有口腔问题"，用大数字制造视觉冲击和认知震撼
2 认知落差 ——"但大多数人从未主动就诊"，点出日常护理缺失的现实
3 解决方案引入 ——"口腔健康，从日常护理开始"，自然过渡到产品

政策契合

  • 《健康口腔行动方案（2019-2025年）》——推动从"疾病治疗"转向"健康管理"
  • 《牙膏监督管理办法》（2023年12月实施）——功效宣称合规，已在页面注明"经实验室实证"
  • 《广告法》第十一条——数据引用标注来源（已标注第四次全国口腔健康流行病学调查等）

3设计理念与视觉方向

美学定位

页面采用新中式奢侈美学的设计语言，以云南白药124年医药底蕴为根基，融合现代轻奢视觉元素。调性克制而精致，沉稳中透露出自信。以深海军蓝为底色，香槟金为提亮，营造医药专业感与高端质感的平衡。不像传统电商页面的"叫卖式"设计，而是以杂志式编辑手法传递品牌故事。

色彩系统

海军蓝 #0f1b2d
亮海军蓝 #1a3050
香槟金 #c9a96e
金亮色 #e8d5a8
奶油白 #f7f5f0
茶绿 #7a9e7a

字体系统

用途字体字重
标题/展示Noto Serif SC（思源宋体）700, 900
正文/UINoto Sans SC（思源黑体）300, 400, 500, 700

选择 Noto Serif SC 作为标题字体，是为了传递云南白药百年品牌的历史厚重感与东方韵味。搭配 Noto Sans SC 作为正文，保证长篇幅阅读的清晰度。

5视觉与交互设计

滚动揭示动画

  • .reveal 类——CSS transition + JavaScript IntersectionObserver，在元素进入视口时触发透明度与位移动画
  • GSAP 高级动画——三大功效卡片区域使用 GSAP fromTo 动画，实现更复杂的入场效果
  • 滚动进度条——页面顶部实时显示阅读进度

Before / After 对比滑条

  • 纯 JavaScript + CSS 实现，不依赖外部库
  • 拖拽滑块切换"使用前/使用3天后"效果
  • 配合"3天提升10个色阶"的数据宣称，提供视觉化佐证

护牙知识闯关游戏

三关设计：行为分类 → 误区戳破 → 笑容海报生成。全前端 JavaScript 实现，游戏化设计提升页面互动率和停留时长。

交互细节

Magnetic Button

鼠标悬停时按钮跟随鼠标偏移

Ripple Effect

点击按钮产生波纹扩散效果

国货点赞

LocalStorage 持久化点赞计数

响应式导航

固定导航栏 + 响应式汉堡菜单

6数据引用与合规说明

页面中引用的所有数据均标注了来源，确保符合《广告法》第十一条关于数据引用的规定：

数据来源标注
"中国成年人口腔疾病患病率超过90%"第四次全国口腔健康流行病学调查
"96.7%成年人有牙结石"第四次全国口腔健康流行病学调查
"87.4%成年人牙龈出血"第四次全国口腔健康流行病学调查
"58%成年人牙齿敏感"中华口腔医学会
"9亿牙周病患者"《促进牙周健康中国专家建议》
"连续7年行业第一"尼尔森2019-2025销售额数据
"3天提升10个色阶"经实验室实证（标注实际效果因人而异）

合规处理要点

  • 功效宣称（抗渍、抗牙结石、抗牙菌斑）均在《牙膏分类目录》允许范围内
  • "行业第一"标注了数据来源（尼尔森）和时间范围（2019-2025）
  • 避免了对竞品的直接贬低表述（"传统美白牙膏靠研磨剂"改为中性描述）
  • 用户评价证言为虚构示例，非真实消费者反馈，在比赛场景下使用

7技术实现

技术栈

核心框架

纯原生 HTML5 + CSS3 + JavaScript，不依赖任何前端框架

动画引擎

GSAP 3.12.5（GreenSock Animation Platform）高级滚动动画

字体加载

Google Fonts：Noto Serif SC + Noto Sans SC

滚动监听

IntersectionObserver API 滚动触发揭示动画

性能优化

  • 图片使用 loading="lazy" 属性延迟加载
  • CSS 动画优先于 JavaScript 动画（减少主线程阻塞）
  • 字体使用 font-display: swap 防止阻塞渲染
  • 响应式设计——面向移动端和桌面端

8总结

设计核心

云南白药光钻白PRO详情页的设计核心在于将社会价值嵌入产品叙事。通过真实数据的引入，页面不再是一个单纯的电商详情页，而是一个具有社会洞察的整合传播方案。

数据板块的加入让消费者在了解产品之前先意识到问题的严重性，从而建立更强的购买动机。同时，通过品牌传承、破除误区、互动游戏、对比体验等多层次内容，页面实现了从品牌信任到产品认知再到购买转化的完整链路。
